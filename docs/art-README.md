# Art

The reproducible Preview sources are `Preview-source.png`, `echo.png`,
`ModIcon-source.png`, and `Preview.config.json`. Run
`node ../scripts/Render-Preview.cjs` from the repository root. The shared
renderer writes the two About images, `Gallery/0-preview.png`, and both ICOs;
temporary checks live under `.render/`.

`ModIcon-original.png`, `ModIcon-cutout.png`, `Preview-without-icon.png`,
`Preview-with-icon.png`, `Preview-before-accent-fix.png`, and
`Preview-cyan-source.png` retain the earlier source and edit history.
